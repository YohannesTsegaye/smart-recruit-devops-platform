# Application Layer

This directory is reserved for the application code and deployment-facing app metadata for the portfolio project.

The current implementation keeps the backend and frontend in their existing project folders while the repository-level deployment and operations files are organized under the required top-level directories:

- `smart-recruit-backend/` — NestJS API service
- `smart-recruit-frontend/` — React UI

This structure keeps the project reproducible while preserving the original working app code.
